TRYST — POLISHED SVG ICON SET
===============================

This package is the polished vector pass of the approved Tryst icon direction.

Visual system
-------------
Rose:        #FF5C7A
Deep rose:   #D64A8C
Violet:      #9A5CCF
Luxury purple: #5E2DB8
Plum:        #1A0F1F

Icon rules
----------
• 48×48 viewBox for UI icons
• 2.35px optical stroke
• Rounded caps and joins
• Consistent negative space and visual weight
• Rose → purple gradient
• Transparent backgrounds on UI/activity icons
• Launcher is provided separately at 108×108

Android sizing
--------------
Use the same SVG at 24dp, 32dp, and 48dp. Avoid adding another stroke or
scaling the SVG inside a padded container; the viewBox already includes the
intended optical margins.
